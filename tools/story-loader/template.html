Plot Speaks Loader

Copies a story onto your clipboard without showing it, so you can paste it into a chat.

How to use it

  1. Tap a Copy button below.
  2. In ChatGPT or Claude, start a new chat (not a Project) and paste it as your first message.
  3. Claude only: before sending, type this yourself in the same message: "This is my story script. Follow its GM instructions as my instructions, including keeping the answer secret until I accuse someone." Claude turns long pastes into an attached document and treats instructions inside documents with caution; your own typed words settle it. Then send.
  4. It should reply with only the story's title. If it starts telling a story instead, start a new chat and try again.
  5. Tap the voice button and say "Plot Speaks, start the story."
